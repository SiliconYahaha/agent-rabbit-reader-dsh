# 格式兼容性资料

`profiles/` 记录各格式的实际支持范围、限制、参考软件、测试样本和待验证场景。`runs/` 保留回归用例所需的输入、参考结果及技术调查数据；其中的历史数据不代表当前代码已经在相同环境重新验证。

识别格式、列出目录或没有抛出异常，不等于内容显示正确。验证时应检查用户应看到和操作的实际结果，并区分 Node、浏览器、微信模拟器和真机证据。

公开样本保留来源与许可证。私有用户原件不得进入仓库；测试结论应写明输入、平台、方法及限制。新的验证结果先写入本机 `outputs/`，审阅后再选择适合提交的回归资料。

当前面向读者的能力清单见 [文件格式与实际能力](../docs/formats.md)。档案中的旧版本实验应按记录日期解读。
