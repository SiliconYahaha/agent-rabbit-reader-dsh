# 文件格式与实际能力

当前代码登记 **80 个扩展名**。这包含完整正文、条件预览、部分内容和仅识别信息等不同能力，不能理解为所有文件都能完整还原。

清单按当前 `miniprogram/file-reader/shared/format-capabilities.js` 整理；设备差异、文件版本、编码和复杂特性均可能影响结果。

| 扩展名 | 实际展示 | 主要限制 |
| --- | --- | --- |
| `html` `htm` | 本机解析正文、图片、表格、样式，并在安全沙箱中执行常见页面交互。 | 浏览器专有 API、跨域网络资源和超大页面可能降级。 |
| `xhtml` `xht` | 按 XHTML MIME 或扩展名解析 XML 字符数据与标签，显示真实正文和样式。 | 不加载外部 DTD/实体，不支持内部 DTD、未知命名空间和完整 XML DOM API；要求 XHTML 根及 body，解析错误明确停止。 |
| `txt` | 识别 UTF-8、UTF-16、GBK/GB18030 后显示完整纯文本。 | 超过 5 MB 暂不直接排版。 |
| `base` | 本机解压 gzipSnapshot 并显示只读表格，可查看原文。 | 附件仅显示名称，复杂字段/视图不完整还原；压缩内容约 1 MB、展开 4 MB、1000 行、64 列和 16000 单元格限制，不恢复在线协作。 |
| `json` `csv` | 在本机读取 JSON、CSV，保留数值、键名和单元格字符串；可切换查看原文。 | 仅阅读，不编辑文件或执行公式；超出排版保护上限或格式无效时明确显示完整原文；文本文件上限 5 MB。 |
| `jsonl` `ndjson` `yaml` `yml` `xml` `tsv` `log` `js` `mjs` `cjs` `ts` `css` `py` `sh` `sql` `ini` `toml` `conf` | 显示文件中实际保存的源码、配置、日志或数据文本。 | 不运行代码、解析 XML 外部实体或展开配置变量；不声称 React 组件预览；文本文件上限 5 MB。 |
| `md` `markdown` | 将标题、列表、表格、链接、代码块和任务项渲染成阅读页面；front-matter 以 meta 事件交给宿主，TeX 公式转成可读 Unicode，脚注、定义列表、diff 高亮、==高亮==、上下标进入正文，mermaid 代码块的流程/时序/状态/甘特图画成 SVG。 | 危险 HTML 会被净化；饼图、类图、ER 图等其他 Mermaid 图型只显示源码占位；公式不做二维排版。 |
| `rtf` | 按 RTF 代码页提取正文、段落和常见 Unicode 字符。 | 暂不还原复杂排版、浮动对象和嵌入文件。 |
| `svg` | 净化后显示矢量图形。 | 外部资源与危险脚本会被移除，超大 SVG 会拒绝。 |
| `pdf` | 在当前阅读页逐页显示 PDF、输入密码、放大和重试；文件切换始终留在小程序内。 | 页内文件上限 25 MB；加密、部分图像编码、复杂色彩效果及超大页面可能受限，不执行 PDF 脚本或表单。 |
| `doc` `docx` `docm` `xls` `xlsx` `xlsm` `ppt` `pptx` | 本机读取 Word 正文、表格和内嵌图片；Excel 显示工作表、合并单元格与保存的公式结果；PPTX 按页显示文字图片表格，旧 PPT 显示当前各页正文。 | 单文件 25 MB；Word 复杂版式、Excel 图表、PPT 动画及精确版式未还原，旧 PPT 图片暂未还原。工作表每张最多 1000 行、50 列，总计 40000 单元格；不执行宏或外部链接。 |
| `png` `jpg` `jpeg` `gif` `webp` | 在当前阅读页显示原图，点击切换放大和适合宽度。 | 实际图片编码解码能力由微信客户端提供。 |
| `ai` `ait` `eps` | 优先打开 Ai 内嵌 PDF；旧式 PostScript Illustrator 文件会在本机还原基础矢量路径，路径无法安全还原时继续解码 DSC/EPSI 屏幕预览位图。 | EPSI 只是文件内低分辨率屏幕预览；没有 PDF 的现代专有编辑数据，以及旧式文件中的渐变、剪切蒙版、字体、链接图片和专有效果尚不能完整还原。 |
| `psd` `psb` `psdt` | 显示内嵌缩略图；没有缩略图时可从 Raw、PackBits RLE、ZIP 或 ZIP Prediction 合成通道还原画面。8-bit 索引色（含透明索引）、8/16-bit 灰度/RGB/CMYK/Lab 与 32-bit RGB/灰度可生成本机 JPEG。 | CMYK 当前使用无配置文件近似预览，Lab 按 D50 转 sRGB；索引色透明区域以棋盘格显示。双色调、多通道、超大画布和复杂独立图层效果尚未完整还原。32-bit CMYK/Lab 缺少可靠格式证据时会拒绝伪造颜色。 |
| `fig` `sketch` | 从现代 Figma 本地副本或 Sketch 文档包读取保存的预览图；Sketch 同时显示页数。 | 不还原完整画布、全部画板、原型或图层；不带预览的旧版/二进制源文件需先导出 SVG、PNG 或 PDF。文件上限 40 MB，Figma 画布条目上限 24 MB，预览上限 8 MB / 1600 万像素，不解密。 |
| `flac` `m4a` `ogg` `ape` `amr` `wma` `wav` `mp3` `aac` `aiff` `aif` `caf` | 读取容器、编码、采样率和声道线索，并在当前平台支持时提供真实播放、暂停、进度和错误反馈。 | FLAC/OGG/APE/AMR/WMA 仅 Android；AIFF/AIF/CAF 仅 iOS；其余仍受文件实际编码与微信版本限制。 |
| `mp4` `mov` `m4v` `3gp` `avi` `m3u8` `webm` | 读取容器和轨道编码线索，在当前平台支持时显示原视频，并报告元数据、缓冲、结束或解码错误。 | MOV/M4V/AVI 仅 iOS，WEBM 仅 Android；聊天中单独选择的本地 M3U8 只能列出分片/密钥引用，不能恢复未同时提供的资源。 |
| `zip` | 按中央目录打开 Store/Deflate；Unix 符号链接在包内解析到真实文件或目录，也支持相对路径和中间目录链接。加密或非常见方法在 80 MB 内切换本机 7-Zip 内核，核对成员序号、大小、CRC和类型；BZip2链接及解锁后的AES目标可打开真实正文。无编码标记时自动尝试UTF-8，否则使用CP437；也可选择UTF-8、CP437、GBK、Shift_JIS、CP949/EUC-KR或Big5，兼容内核继续按同一真实成员打开。支持数字分卷及z01 + zip。 | 卷组合计80 MB、单文件20 MB、最多10卷。链接限16层及4096 B，拒绝越界、循环、缺失、隐藏项和重名；兼容内核只读取隔离内存副本，不创建宿主链接、不修改原文件。不支持的方法只禁用对应成员；ZIP64旧编码与分卷链接组合仍待验证，EUC-JP尚无选择。 |
| `rar` | 由本机 RAR 内核显示 RAR 4/5 目录树，打开 Store/Normal 文件及加密内容；普通符号链接、RAR5 硬链接和文件复制记录可定位包内真实目标，文件夹链接可显示子目录或作为中间路径继续打开真实子文件。RAR4 未标记 UTF-8 的旧式路径会自动保留可逆字节，也可明确选择 UTF-8、CP437、GB18030、Shift_JIS、CP949 或 Big5，文件名与链接目标使用同一编码并仍按原生成员身份解压。一次选中的 partN.rar 或 rar + rNN 卷组交给 7-Zip 内核展开，并在安全解析链接后按成员身份打开跨卷真实目标。 | 卷组合计限制 80 MB、单文件 20 MB、最多 10 卷；链接限 16 层及 4096 B 目标，拒绝越界、循环和同名歧义。RAR5 重定向目标仍严格要求 UTF-8；加密分卷中的链接组合及 iOS/Android 真机内存边界仍待验证。 |
| `7z` | 按需加载本机 7-Zip 内核，显示目录树，打开 Copy、LZMA、LZMA2 等常见条目并解锁加密内容；一次选中的 .7z.001/.002 会合并显示真实目录和正文。 | 卷组合计限制 80 MB、单文件限制 20 MB、一次最多选择 10 卷；缺卷、旧版微信和真机内存边界可能阻止解压。 |
| `tar` | 在本机读取未压缩 TAR，按成员序号打开正文；符号链接按所在目录解析，硬链接引用先前成员。 | 整包80 MB、单文件20 MB，链接16层及4096字节。设备和FIFO条目不能作为普通文件阅读；拒绝越界、循环及符号链接目标歧义。gzip/xz包装、TAR分卷及真机组合尚待验证。 |
| `dxf` | 显示常见二维图元、SPLINE、BLOCK/INSERT、HATCH 与 DIMENSION；并把三维 LINE、3DFACE、3D POLYLINE、polygon mesh 与 polyface mesh 还原为可旋转点边面模型。 | 非平面样条、复杂周期样条、三维圆弧/实体、动态块、代理对象、块的三维变换、图层颜色与完整线型尚未还原。 |
| `stp` `step` | 显示 STEP 文件头与实体统计，把点和 EDGE_CURVE 转成可旋转线框，把 FACETED_BREP、常见解析曲面及非有理/有理 B 样条自由曲面三角化，并按 MAPPED_ITEM 或 ITEM_DEFINED_TRANSFORMATION 坐标链展开常见装配实例。 | 复杂裁切、孔洞、局部主轴角裁切、布尔裁切、单位不同的装配上下文、超过 16 层或 200 个实例的超大装配仍受本机保护上限限制；无法可靠成面时只显示文件中的真实边界。 |
| `dwg` | 仅显示 DWG 保存版本；文件本身实际带有 JPEG/PNG 时显示该缩略图，并明确标记这不是图纸预览。 | 当前版本不支持 DWG 几何内容。LibreDWG/WASM 为 GPLv3，RealDWG 与 ODA Drawings 为商业授权；本项目也不把用户文件上传到云端转换。请先在 CAD 软件中另存为 DXF。 |
| `cdr` | 旧式 RIFF 文档会解开 LIST cmpr 的双 zlib 数据流，从 loda / trfd / fild / outl 还原基础路径、填色、描边和对象变换；DISP/JPEG/PNG 只作回退。现代 ZIP 文档包显示目录、内嵌预览，并可打开支持的内部文件。 | 当前压缩矢量解释器重点覆盖 CDR 6–12 常见矩形、椭圆、直线/贝塞尔路径和多边形；艺术字未转曲、段落文字、位图对象、复杂渐变/图案、透明、镜头和专有效果仍可能缺失。 |

## 如何判断支持

应检查用户实际看到的正文、画面和交互，不能仅凭文件识别成功、目录出现或没有报错下结论。错误会明确提示；在安全和资源限制内使用可用的预览或原文。

Node 测试、浏览器对照、开发者工具和真机验证分别记录。具体示例见 [内置示例](format-use-cases/README.md)，技术证据见 [兼容性档案](../compatibility/README.md)。

## 内容能力登记

按内部等级统计：正文内容 32、微信原生 0、条件内容 34、部分内容 13、内容未支持 1，合计 32 + 0 + 34 + 13 + 1 = 80。等级标签不替代上表中的具体限制。当前唯一明确属于“内容未支持”的扩展名是 **DWG**。
