# 1.4.159 · 阅读体验与格式预览更新

本次同步更新文件阅读代码及资源，并整理开源文档与产品展示。

- PDF 在阅读页内显示，补齐中文文本解码、页面绘制与失败恢复。
- Word、Excel、PowerPoint 提供正文、表格及幻灯片内容阅读；BASE 支持只读快照表格。
- 改善 Ai / EPS、PSD、Figma 与 Sketch 预览，使用彩色兔子阅读器 Logo 作为 Ai 示例。
- 改善 HTML / SVG 渲染、文件队列、返回路径、最近阅读和粘贴 HTML 面板。
- 保留深嵌套 JSON 的缩进体积保护。
- 首页加入横向海报与 20 秒视频，统一支持格式和开发文档。

交付范围为 GitHub 源码与文档，不包含微信开发版上传、体验版、提审或正式发布。Node 回归、生成资源、渲染烟测与生产边界按本次提交重新验证；浏览器、开发者工具和真机不冒用此前版本的通过结论。
