# 首页案例预览

这些素材用于仓库首页展示，不打包进小程序。点击首页预览可查看大图，交互操作需在小程序内体验。

| 素材 | 内容与来源 |
| --- | --- |
| `koi.gif` | 锦鲤唱片机，用户提供的真实操作动图，来自产品演示视频 |
| `tank.gif` | 坦克大战，用户提供的真实游戏动图，来自产品演示视频 |
| `bicycle.svg` | 秦始皇骑自行车，保留原始 SVG 动画 |
| `search-ai.png` | 「搜一搜小程序物料源文件.ai」预览，码为素材占位码 |
| `psd-poster.png` | 小程序内 Mozilla 吉祥物发布海报 PSD 示例的彩色预览 |
| `markdown.png` | 周末闪现计划 Markdown 画面，来自产品演示视频 |

素材由用户指定的本地展示页导入，文件原样保留。来源与署名继续遵循 [示例素材说明](../../../scripts/assets/example-art/README.md)。这些预览不代表同一格式的所有文件或设备均得到完整支持。
