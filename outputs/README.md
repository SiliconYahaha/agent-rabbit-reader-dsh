# 本地输出与审核材料

这个目录属于 HTML 阅读器项目，用来集中保存开发过程中生成的预览二维码、微信上传记录、验收截图、审核图片和审核视频。它不是另一套项目。

目录中的生成文件默认不提交 GitHub，避免把失效二维码、失败录屏、设备截图和较大的中间文件混入代码历史；本说明文件除外。

主要内容：

- `design-review-*`、`redesign-audit-*`、`ux-*`、`fidelity-*`：设计与显示效果的阶段性验收材料。
- `deploy-*`、`release-*`：各开发版本的上传记录和预览二维码。
- `review-1.2.1-2026-08-16/`：1.2.1 首发审核使用的截图、视频、文案与状态记录。
- `editable-design/`：可编辑设计稿及其预览。

项目代码、正式文档和可长期复用的品牌资源仍分别保存在 `miniprogram/`、`docs/` 与 `docs/assets/`。
