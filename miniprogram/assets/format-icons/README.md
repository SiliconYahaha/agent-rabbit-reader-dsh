# Format icons

Project-authored SVG interface icons describe file types. Ai/Ps and MD are text labels, not company logos or endorsements. HTML remains unchanged.

SVG and ZIP use the Tabler Icons `file-type-svg` and `file-zip` paths, resized and colored for the interface. MIT license: see LICENSE-tabler.txt.
